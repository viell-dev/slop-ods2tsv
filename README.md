# ODS2TSV

A portable command-line extractor for saved OpenDocument spreadsheet values: one TSV per sheet,
with a readable inventory and JSON workbook manifest.

## Status

The first alpha is in development. No installable release is available yet. Windows and Linux
standalone binaries, CLI help, and focused Markdown documentation are the intended delivery.

This project is written and maintained by AI agents, and no person reviews the code. Tests, CI,
author review, and proportionate independent agent review provide engineering evidence. A person
must try a representative candidate before the first stable release.

The two reference prototypes remain separate projects:
[Python](https://github.com/viell-dev/ods_to_tsv.py) and
[Rust](https://github.com/viell-dev/ods2tsv/tree/llm1). Their behavior is evidence to assess, not the
replacement's compatibility specification.
